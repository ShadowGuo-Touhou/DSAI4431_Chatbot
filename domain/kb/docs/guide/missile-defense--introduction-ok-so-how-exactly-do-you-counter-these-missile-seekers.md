## Body
We have finally arrived to the main meat of this guide: how to effectively softkill certain seeker types.

In nebulous you will commonly hear about the "Softkill Checklist" which is as follows:

- Chaff + Flare + Active Decoy

- ALLSTOP / go backwards

- EMCON

- CMD jamming (Omnidirectional) + EO jammer

- Self illumination

- Killjoy jammer decoys

This checklist is what is commonly accepted as the actions necessary to effectively softkill every type of seeker type. Of course there are other ways to softkill certain seekers, with some ways being more effective than others, but this is what you need to do in order to softkill EVERY seeker in the game (validated seekers included).

Now for specific seekers, I will explain the mechanics behind them and the proper counters to them.
