# Beginner's Guide › Detecting enemies › Burn Through

Source: Official wiki (wiki.hoodedhorse.com), game 0.6.2.6:260903-1430

## Body
The following is a technique on some radar systems such as the Parallax that allows a burn through lock, in which a high powered "sonar" ping is able to see through the jamming for a moment in time.

As can be seen a purple circle is placed on each detected ship. Again, this track is a single moment in time, meaning that if the enemy ship moves away from the purple circle, your radar will not report its change in position and any shots you fire miss.
