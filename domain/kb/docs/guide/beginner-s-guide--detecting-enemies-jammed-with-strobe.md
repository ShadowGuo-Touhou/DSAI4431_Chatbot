Source: Official wiki (wiki.hoodedhorse.com), game 0.6.2.6:260903-1430

## Body
If you have a Strobe Correlator, you may be able to detect the direction in which the Jamming is coming from. If you have multiple strobe correlates on different ships you can generate a cross fix and a fireable track.

As can be seen in the Image the "J" in the tactical map shows the direction relative to the ship that detected the jamming (Note, it doesn't detect distance without a crossfix). Note you need to select an origin ship first (Identified with a blue dotted X on the ship I selected with a left click) for the J to appear.
