Source: Official wiki (wiki.hoodedhorse.com), game 0.6.2.6:260903-1430

## Body
Modules take up internal space within module slots, each conferring some benefit (and, sometimes, a downside.) Unlike compartments, there are no modules which scale with the size of the compartment they're fitted to: modules should generally be put in the smallest slot available for that module.
