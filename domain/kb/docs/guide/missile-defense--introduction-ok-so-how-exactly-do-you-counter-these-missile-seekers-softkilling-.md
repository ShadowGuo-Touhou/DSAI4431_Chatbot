# Missile Defense › Introduction › Ok, so how EXACTLY do you counter these missile seekers? › Softkilling Electroptical Seekers

Source: Official wiki (wiki.hoodedhorse.com), game 0.6.2.6:260903-1430

## Body
This seeker is an ANS exclusive seeker which visually checks a target, meaning it cannot be discriminated by any type of decoy.

The most direct (and only) counter to an EO seeker is a blackjack dazzler, which is only available on OSP. This is probably one of the simplest types of seekers to counter, but requires a dedicated mount to do so. EO seekers in the jamming cone of a dazzler are blinded; EO seekers remain blind for 1 second after exiting the cone due to the Dazzler's "Stun" mechanic.
