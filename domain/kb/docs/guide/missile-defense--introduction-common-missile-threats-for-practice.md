I've basically covered everything you need to learn about softkill. To finish off, lets go over some common threat examples:

OCELLOKILLER S3H SIZE 3/6 SALVO: CMD/ARAD, CMD/HOJ, CMD/SAH. You will most commonly see this playing against ANS as OSP. Fired at mainly at Ocellos, but can be fired at Flatheads and Marauders as well.

How to softkill:

- Decoy with Chaff and Flares

- EMCON (for ARAD, must be done first as it also turns off the Interrupt)

- Interrupt CMD jammer activation (for CMD)

- Turn on your illuminator, point it towards your chaff. (for SAH)

- Fire a Killjoy jammer decoy or have an offset jammer ready. (for ARAD/HOJ)

ACT/[WAKE] and ACT/[THERM] MISSILES How to softkill:

- Decoy with Chaff and Flares (for ACT)

- ALLSTOP if going forwards to avoid using forward thrusters, otherwise plot backwards with heading locked so the ship does not turn around. A plain move order faces the destination and burns the main drive. Braking a backward drift also emits wake. (for WAKE and THERM validation).

CONTAINERS: CMD/SAH/HOJ, CMD/ACT/[THERM], CMD/WAKE/[HOJ]
