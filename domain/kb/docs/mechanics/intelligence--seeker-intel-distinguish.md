# Intelligence › Seeker intel distinguish

Source: Official wiki (wiki.hoodedhorse.com), game 0.6.2.6:260903-1430

## Body
If a ship class and/or hull type is identified, Seekers with intel distinguish capability (Such as EO seekers) are capable of using that intel to identify and focusing on a specific class or hull if fired in TRK(track) mode. Note that this cannot seek out specific ships by name, it only gets as specific as the hull type.
