- 另有弹库 0 点 + 弹药 97 点 ⇒ **全价约 452 点**（估算；游戏里以存档原值 452 为准，单价见 `zh/弹药点数表.md`）
- 供电：发电 3650 kW / 耗电 3500 kW（余量 +150 kW）
