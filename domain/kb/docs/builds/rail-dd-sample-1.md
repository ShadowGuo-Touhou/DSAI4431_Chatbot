## 样板船完整装配（整艘照抄）：BFR（hc gun dd test 11）

- 合计：部件 175 点 + 舰体 200 点 = **375 点**（不含弹库与弹药，见下）
- 另有弹库 0 点 + 弹药 16 点 ⇒ **全价约 391 点**（估算；游戏里以存档原值 466 为准，单价见 `zh/弹药点数表.md`）
