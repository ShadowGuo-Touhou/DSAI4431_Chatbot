# Components › Mounts

Source: Official wiki (wiki.hoodedhorse.com), game 0.6.2.6:260903-1430

## Body
Mount components are installed on the exterior of the ship's hull and grant the ship certain capabilities, whether that be utility, defense, or offensive capability. Almost all mounts are faction-exclusive, with only a few cross-compatible mountings between factions like the VLS-1 launchers. Some ships even have access to mountings from other factions, like the Ocello class Command Cruiser on OSP.
