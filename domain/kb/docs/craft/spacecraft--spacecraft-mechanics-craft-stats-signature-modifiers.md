## Body
| Source | Radar signature | Detection range |
|---|---|---|
| Stealth Coating (craft fuselage) | −50% | ×0.84 |
| Flight of 6–10 craft | +15% | ×1.04 |
| Flight of 11–15 craft | +30% | ×1.07 |
| Flight radars off | −5% | ×0.99 |
| Radar Absorbent Coating (missile support module) | −40% | ×0.88 |

- Craft modifiers multiply: the craft's own stat × the flight's stat.

- The flight-size values are the defaults in the game code. The values set for flights in the game data were not read.

- If a flight has two modifiers, the smaller one counts at only about 37% of its value. A flight of 6–10 craft with radars off is +13%, not +10%.
