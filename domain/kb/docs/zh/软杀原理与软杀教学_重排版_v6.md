## 引言：软杀是什么，以及为什么它重要

软杀（Soft-kill）指通过电子战、诱饵与机动等手段，让来袭导弹失去正确目标或锁定错误目标，从而保护舰船。

本文目标：把软杀拆成能执行的动作链，并给出一套实战可用的标准动作（SOP）。

常见软杀手段（按机制分类）：

主动干扰：雷达干扰、通讯干扰、EO 干扰等，使导引头在噪声下偏离目标。

诱饵：箔条（雷达诱饵）、Flare（尾流/热诱饵）、主动诱饵、诱饵集装箱等，让导弹优先追逐假目标。

机动躲避：高机动小船通过侧拉/变向躲开低机动威胁；结合侦察可提前识别 TOT 集装箱并规避。

利用导弹/导引头特性：部分混合导引头在特定干扰下会提前分级，可能导致二级射程不足而自毁（取决于版本与配置）。

## 一、主引导头、副引导头与验证头

理解这三个概念，是理解导弹目标选择与软杀原理的基础。

主引导头：安装在主引导头槽位（从右往左数，第一个装了引导头的槽位）的引导头，优先级最高。

副引导头：安装在比主引导头更靠左的引导头槽位，优先级从右到左依次递减；当主头锁定目标时，副头不生效。

验证头：占用引导头槽位但不进行制导；用于筛选/标记优先目标，影响导引头的目标选择。

原理补充（原文链接）：https://www.bilibili.com/opus/835928235008065590

## 二、导弹目标选择逻辑（用 1/0 做速查）

导引头面对不同状态目标时，选定优先目标的逻辑遵循：

主头锁定目标时副头不生效。

通过验证头验证的目标优先于未通过验证头验证的目标。

拒绝接受未验证目标的主头在验证未通过时不生效。

用 1 和 0 表示导弹追踪目标优先度（保持原文逻辑）：

## 标准双导引头（主头 + 副头）

优先程度：1/1 = 1/0 > 0/1 > 0/0

## 主头 + 验证头（接受未经验证目标）

优先程度：1[1] > 1[0] > 0[1] = 0[0]

## 主头 + 验证头（拒绝未经验证目标）

优先程度：1[1] > 1[0] = 0[1] = 0[0]

注：双验证头有 bug，没法用。

## 三、复合软杀与实战标准动作（SOP）

主/被动软杀组合后可以覆盖大多数威胁。核心思路：能让软杀链条变成 0 的尽量变成 0；不能变成 0 的，就用诱饵把导弹的目标清单塞满 1，让它追错。

示例：面对混合来袭 ACT[WAKE]+EO / ACT+CMD / ARAD+CMD / ACT+ARAD / ACT，可按顺序：

停船或倒车，主引擎关机，让 [WAKE] 变成 0。

EO 干扰对准导弹来袭方向开机，让 EO 与 [EO] 变成 0。

关闭导弹目标范围内的雷达与雷达干扰（包括火控雷达），让 ARAD 与 [ARAD] 变成 0。

CMD 干扰启动，让 CMD 与 [CMD] 变成 0。

根据舰船大小释放 1–5 个诱饵，让 ACT 锁定错误目标。

## 实战 SOP：

听到大量导弹警报：主力舰立刻主引擎停机；判断导弹攻击目标；CMD 干扰开启。（EO 干扰可自动对准，但建议手动。）

若确认攻击目标为自己：立刻关闭目标区域内全舰雷达（包括火控雷达），并撒一定量箔条。

## 四、各个引导头的软杀操作

## #主动雷达头（ACT）

作为引导头: 1.发射箔条诱饵或EA99主动诱饵或OSP的诱饵集装箱（必须）

雷达干扰（可选，但会被烧穿）

作为验证头：让主头失效

## #半主动雷达头（Sah）

作为引导头: 1.发射箔条/EA99/OSP的诱饵集装箱并让船呆在诱饵附近（必须）

2. 用一个照明器在和来袭导弹同一个半球的角度内照明诱饵（可选，推荐）

雷达干扰（可选）

作为验证头：作为引导头时的软杀操作 + 搞定主头

## #指令制导（CMD）

作为引导头和验证头:

1.通讯干扰并在功率上压制发射船的通讯功率。（推荐）

2.雷达干扰敌方传感器，让敌方的追踪精度变差（难度高）

## #反辐射（ARAD）与反干扰辐射（HOJ）

反辐射分“All Emission”和“Pulse only”。HOJ头也附属在Arad系列中。All Emission 追雷达发射和雷达干扰源；Pulse Only只追踪雷达。

注：1. 所有ARAD和HOJ验证头有30秒记忆。即：船只通过验证后哪怕关了雷达，30秒内也会被当作开着雷达。

2. ARAD(Pulse) 吃雷达干扰会乱飞。

## #尾流制导(WAKE）与尾流热能制导（THERM)

Wake和Therm看的都是船只主发动机点火是产生的尾流。

Wake:大型船只点火后需要冷却15秒才会回到看不见尾流的状态。且只有在船只后半球120度的锥子里面才有效。

Therm:尾流热信号大于150才会被看见。大船主发点火产生尾流信号，然后慢慢冷却到0。Therm是所有方向都能看见目标尾流。

Wake作为引导头：1. 让船持续往船尾方向移动（倒车）（推荐）

2.打Flare诱饵（可选)

3.把船体对准导弹来袭方向（可选)

Wake作为验证头：上文 1和3；并搞定主头

Therm引导头：同Wake引导头

Therm验证头：同Wake验证头

## 五、直航弹的软杀（进阶内容）

直航弹：没有导引头，或利用导引头与目标选择逻辑，使导弹在被干扰前对准目标、在满足被干扰条件后保持直线飞行，从而命中目标。典型例子：OSP 火箭；以及一系列主头拒绝 [CMD]，或 CMD/WAKE、CMD/HOJ、近距离 ARAD 等直飞构型。

## 形成原理（按原文语义整理）：

利用干扰圈外调整冲刺方向，在进入干扰圈前对准目标。

进入干扰圈后：[CMD] 验证失效，或 CMD 在圈外预瞄准并锁定路线，进圈后沿既定路线继续前进，拒绝除对应干扰外的一切偏转扰动。

在部分配置（如 ARAD[CMD]）中，只要在通讯干扰强度盖过导弹接收通讯强度之前完成路线设定，就很难被末端扰动影响。

软杀方法：末端直线且几乎无机动 -> 类似软杀火箭，改变目标舰运行轨迹即可让其打空。

难点：末端反应时间往往极短（原文举例最后 4km 可能仅数秒），因此常需要偏置舰的主动干扰对其进行末端扰动。

注：任何 ACT[CMD] 直飞导弹在吃到两种干扰后往往会乱飞；ACT[EO] 同理。

## 六、偏置（导弹调教方法：偏置干扰）

偏置（偏置干扰）指能利用自身主动干扰设备保护导弹核心舰的非核心舰。主要功能：软杀 ARAD 等可利用特性软杀的导弹，并在需要时兼任末端直射弹的扰动任务。

## 明偏置：

本质是主力舰的伴飞，兼任帮助舰队干扰敌舰，也可全向软杀各种导弹。

缺点：容易被发现并针对，且难以通过操作躲避导弹。

经验：慢速导弹场景可卡时间，命中前几秒关闭干扰并释放箔条，让导弹打空。

## 暗偏置：

位于舰队后方、PD 网后方，几乎仅负责干扰敌方导弹（或兼职 EWR/LRT 远距侦察）。

优点：不易被针对；缺点：受干扰方向限制，导弹从非预判方向来袭时可能被无视。

注意：暗偏置离核心舰群过远时，干扰功率可能低于核心舰雷达功率，ARAD 仍可能优先攻击核心舰。

## 七、侦查与软杀反应时间

要完成软杀动作链，必须有反应时间。如果敌方导弹顺着干扰发动攻击，留给玩家的反应时间会很短，软杀难度会上升。

## 侦查与反干扰的重要性：

侦查可探测伏击，为软杀与规避提供反应窗口。

面对极难或不可软杀目标（如近距离 SAH、某些近距离 CMD 直飞弹）时，侦查能提供更多预警与规避时间。

结语（保留原文语气）：这个游戏没有且不应该有万能的战舰，只有坚不可摧的舰队。任何不以舰队协同而设计的舰队都是整活；任何不能与整个舰队协同的单舰舰队都是整活。
