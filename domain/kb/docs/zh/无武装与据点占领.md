# 无武装（unarmed）与据点占领

## 什么是「无武装舰」（unarmed）

判定只看**有没有真正的进攻能力**，不看船体大小、点数多少、是不是侦察船：

- **没有火炮**（cannon / turret / casemate 都算火炮，含轴炮 spinal）
- **没有进攻性导弹**：发射器里装着进攻弹就算有；只装 chaff / flare / decoy（对抗弹）不算
- **没有干扰器**（jammer）
- **没有 arming missile**：1 点钱的进攻性 S1 也算武器 —— 这条最容易漏，便宜的 cap 通常就靠这一发弹算「有武装」

补充：**空发射器不算武器**。VLS-1 挂在船上但没有弹，这条船依然按无武装舰算（游戏里它也打不出东西）。

## 为什么这个定义重要

1. **据点占领优先权**：两条船同时在一个点上时，**有武装的一方**才能推进占领；双方都武装、或双方都无人 =
   争夺中（contested），占领进度**保持不变**（例如「team 1 已占领 + team 2 正在占领 50%」会停在那里）。
   ⇒ 想抢点，至少派一条带武器的船；纯侦察/纯干扰船抢不动。
2. **全队落败**：只要某一队**所有船在同一时刻都是无武装舰**，这一队**立即判负**。
   ⇒ 舰队里不能全是眼船/干扰船/裸 cap，至少要留一条能打的。

## 怎么自查一条船

1. 看有没有炮（含轴炮）——有就不是无武装舰。
2. 看发射器里有没有非对抗弹——有进攻弹就不是无武装舰。
3. 看有没有干扰器——有就不是无武装舰。
4. 以上都没有 = 无武装舰，抢点时按「无武装」算。

## 和舰级分类的关系

`unarmed` 是一个**只用于识别的舰级（detection-only class）**，和 `General DD` 这类 Bad 类同级：
可以拿它判断「这艘船现在算不算无武装」，但**永远不要把它当推荐配法**。

- 一条船可以同时属于多个舰级：`scout ffl` 的侦察船如果没挂武器，同时也算 `unarmed`；
- 判断永远针对**当前配置**，不是船体固有属性——加一发 1 点进攻弹就不再是无武装舰；
- `builds/unarmed-any-hull.md` 只描述语料里这类船长什么样（多数是廉价侦察/诱饵船），
  模板页会写 `Detection only — do not recommend`；回答时只讲怎么认，不要给配置建议。

## 已知不确定

- 占领推进速度的具体数值（每秒多少 %）知识库里没有，游戏内也不显示，不要编。
- 模组（例如 No Ship Limits）可能改变舰队规模与判负条件，遇到模组舰队时把结论降级为「按原版规则判断」。
