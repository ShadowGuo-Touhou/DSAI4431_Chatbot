# NEB 简明指挥术语（中文对应）

来源：玩家整理（中文，非官方，可能早于游戏 0.6.2.6）

这是多人局里打字的简写指令。`<>` 里的内容是占位符，实际不会打出来（比如 `cap <A>` 就是打 `cap A`）。

| 术语 | 含义 |
|---|---|
| cap <A> | 抢占 A 点 |
| deny <A> | 阻止敌方抢占 A 点 |
| def <A> | 防御 A 点 |
| atk <A> | 攻击 A 点 |
| scout <A> | 侦察 A 点 |
| XX position <A> | 某某卡位 A 点 |
| lock <XXXX> | 帮我锁定 XXXX |
| focus <XXXX> | 全队集火 XXXX |
| pincer <XXXX> | 左右夹击 XXXX |
| jam <XXXX> | 电子干扰 XXXX（射导弹前） |
| strike <XXXX> | 导弹打击 XXXX |
| bomb <XXXX> | 飞机轰炸 XXXX |
| finish <XXXX> | 处决船只 XXXX |
| need escort | 需要护航（一般是战斗机护航） |
| flank left/right/top/bottom | 从左/右/上/下绕侧（协调队友） |
| XX we ball | 某某我们抱团 |
| XX tank | 某某去抗线 |
| XX back | 某某后退 |
| XX split | 某某分队（分开队控点） |

## 相关英文用词（对官方 wiki 的对应说法）

| 中文口语 | 官方/英文说法 |
|---|---|
| 抢点、卡位 | capture point / objective control |
| 集火 | focus fire |
| 绕侧 | flank |
| 抗线 | hold the line / screen |
| 电子干扰 | electronic warfare, jammer |
| 导弹打击 | missile strike |
| 处决（补刀） | finishing off / kill confirmation |
