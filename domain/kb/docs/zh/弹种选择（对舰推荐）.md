# 弹种选择（对舰推荐）

Tags: kind=manual; topic=shell choice, 弹种选择, 打什么船用什么弹, AP, HE, RPF, GrapE, HESH, Bomb
Keywords: 用什么弹, 打什么船用什么弹, 弹种选择, AP, HE, RPF, GrapE, HESH, 250mm, 450mm, 600mm, 穿甲, 高爆
Summary: 一张玩家总结的「打哪种船用什么炮弹」对照表（版本偏旧，缺 250mm 炸弹行）；给结论级别的建议，不含数值。

## 通用规则（先看这三条）

1. **先打 AP**：如果炮弹打穿目标，就换 HE——AP 过穿反而不如 HE 打伤害。
2. **如果炮弹在目标表面擦出一片火花（跳弹），换 AP**——火花就是「没打穿、被弹开」的视觉信号（英文原文：*If you see showers of sparks for ricochets*）。
3. **打小船先 RPF/GrapE**——目的是**把它的机动废掉**（打坏推进器、削掉灵活性），让它没法再靠机动躲；瘫了再用 HE 拆。
4. **看装甲挑弹**：装甲值（cm）就是穿深门槛，AP 低于它只会跳弹或擦掉表层；数值见 `zh/装甲与伤害机制.md`。

读法：`X -> Y` = 先用 X 打伤害，打完换 Y 收尾；`X or Y` = 两样都行；`X :-(` = 最理想但效果一般；**粗体 = 只此一个选项**。

## 表格的局限

- **版本偏旧**：原表没有 250mm 炸弹行，但实战口径是 **250 Bomb 打 Sprinter = Bomb -> HE**（和用 RPF 打 Shuttle 同一个思路；缺的这格已补进上面的表）。
- 表里没有数值（穿深、伤害），只有「打谁好使」的结论；要数值去看 `reference/` 下的弹药文档。
- 600mm 只有 `Bomb`（炸弹）和 `HESH`，没有 AP。
- 这张表对**配船时选弹种**很有用：比如给 450 CH 配弹时，主炮弹按 450mm HE/AP 双带，而不是一股脑 AP。
