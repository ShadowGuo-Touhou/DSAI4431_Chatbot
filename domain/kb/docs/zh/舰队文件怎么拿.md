# 舰队文件怎么拿（`.fleet` 从哪来、怎么进游戏）

> 一句话：**不要手写 `.fleet`，也不要指望聊天里贴一份能复制。** 文件由 `build_fleet_file` 工具生成，
> 落在 `repo/fleet output/`，复制进游戏目录即可。

## 1. 三个来源，按优先级

| 来源 | 用法 | 什么时候用 |
| --- | --- | --- |
| `sample fleets/`（61 条现成样板） | 直接复制进游戏，或在工具里选它拼多条 | 想马上开一局、要 good 样本当底子 |
| `build_fleet_file` 工具 | 让机器人拼一条新舰队，命令式生成 | 用户要「帮我配一条 3k 舰队并给我文件」 |
| 手写 / 手改 XML | **不要** | 除非你明确知道槽位 key 与模板库结构 |

## 2. 为什么不能手写 XML

1. **槽位 key 是 22 字符随机串**（`4V6twrIUcEKE11tom-tDXQ`、`T9TN0ZYumUaCxcSRjO_qTw`……）。
   写成 `MT1`、`CMP1` 这种人类编号，游戏的 `SocketMap` 查不到 key，**不会报错，只会跳过**——
   到舰队编辑器里一看，船是空壳，人还以为是「配好了只是没显示」。
2. `<InitialFormation><GuideKey>` 必须指向舰队里真实存在的某艘 `<Key>`。重新生成过 UUID 却忘了改 guide，
   游戏日志会刷 `Fleet is missing guide with GUID ….  The ship X will start independently.`，
   编队直接散架。
3. 发射器的 `$MODMIS$/…`、机库的 `$CRAFT$/…` 靠舰队级 `<MissileTypes>` / `<CraftTypes>` 解析。
   只搬 `<Ship>` 节点、不搬模板库 → 导弹和舰载机变成空引用。
4. 重新滚动 key 时，`<Key>`、`<InitialFormation><GuideKey>`、`SocketMap` 里的 key 必须一起换，
   漏一个就是静默失败。

工具做的事就是这四条：挑船 → 重新分配 key → 修 guide → 搬模板库 → 写盘 → 回读校验。

## 3. 船名怎么定

| 情况 | 做法 | 结果 |
| --- | --- | --- |
| 用户点了名（「叫 灰烬一号」） | `renames: ["灰烬一号", "灰烬二号"]` | 按给的顺序逐条改名 |
| 用户没提名字（多数情况） | **不填 `renames`** | 按舰级自动编号：`450 CH 1`、`450 CH 2`、`450 CC 1` |
| 用户说「保留原名」 | `keep_names: true` | 沿用样板船原名（`Moral Failing`、`Umber Ox`） |

自动命名的前缀取自 `Ship Builds.txt` 的舰级名（去掉括号里的说明、把舰种缩写大写），
所以同一个舰级在一条舰队里永远连号；混编时不同舰级各自从 1 开始，一眼能看出编成。

## 4. 模型该怎么跟用户说话

- 先给结论：**几艘、多少点、哪个阵营、校验过没有**，再把**船名**列出来。
- 再给**文件绝对路径**（`repo/fleet output/<舰队名>.fleet`）。
- 告诉用户往哪放：`<Steam>\steamapps\common\Nebulous\Saves\Fleets\`，游戏里「载入舰队」就能看到。
- **不要贴 XML**。一条 61 艘的舰队文件 50 万字节，贴出来既超上下文也没法用；用户要的是能双击/复制的东西。

## 5. 常见失败与说法

| 现象 | 原因 | 正确回应 |
| --- | --- | --- |
| 载入后船是空壳 | 槽位 key 无效（手写的） | 用工具重新生成 |
| 日志刷 `missing guide with GUID` | guide 指到不存在的船 | 工具生成时自动修；报错就让用户贴日志 |
| 导弹/舰载机不出现 | 舰队里缺 `<MissileTypes>` / `<CraftTypes>` | 同上，必须带模板库 |
| 载入被拒 | 混了阵营（一条 `.fleet` 只有一个 `FactionKey`） | 拆成两条或换同阵营样板 |
| 点数对不上 | 游戏按存档重算（弹库、弹药、舰载机都算钱） | 报「估算点数」，以游戏内为准 |
| 船名重复/怪 | 没传 `renames` 却想要自定义名，或传的名字重复 | 工具会自动加序号，也可以重新生成 |
