# 供电预算与 (n-1) 规则

Tags: kind=guide; topic=power; 供电; 电力; 反应堆; 效率; 关电; n-1

Keywords: power, power supply, reactor, efficiency, plant control center, small reactor booster, brownout, 供电, 电力, 电量, 反应堆, 效率, 断电, 关雷达, 供电不足, 超载, n-1

Summary: 供电 = Σ(反应堆输出 × 效率加成) + 驱动输出；效率来自 Plant Control Center（每个 +20%）与 Small Reactor Booster（每个 +10%）。「110% 上限」的例外就是 (n-1) 规则：允许关掉一个可关部件后仍在额度内。

## 1. 供是怎么算的

```
供电 = Σ round(反应堆单件输出 × (1 + 效率加成)) + Σ 驱动的 Provided Power
```

- **只有反应堆吃效率加成**（游戏里叫 Powerplant Efficiency），驱动提供的是固定值，不乘效率。
- 反应堆：`Boosted Reactor` +5000 kW、`Civilian Reactor` +3650、`Light Civilian Reactor` +1850。
- **驱动也供电**：`BW2000 Drive` +2000 kW、`FM200 Drive` +500 kW —— 算船的电量时别忘了驱动这一列。
- 效率来源：
  - `Plant Control Center`（舱室，25 点，3x1x3，Engineering）：**每个 +20%**。
  - `Small Reactor Booster`（模块，10 点，2x2x2）：**每个 +10%**，额外代价是 **+5% 雷达信号**（更易被发现），而且要占一个模块槽。
  - 部分船体自带修正（例如 Ocello 的 `Powerplant Efficiency +10%`）。
- 例：`Suisei`（Bulk Hauler，1222 点）反应堆 5000 + 1850×2 = 8700，4 个 PCC ⇒ ×1.8 = 15660，再加 BW2000 的 2000 ⇒ **17660 kW**。

## 2. 用是怎么算的

**所有耗电部件都要算**：火炮/近防的 Required Power、推进、雷达、干扰器、L50 激光 dazzler、Energy Regulator（650 kW）、Small Energy Regulator（400 kW）等。别只算反应堆和引擎。

三类耗电：

| 类 | 典型部件 | 平时 |
| --- | --- | --- |
| hard（常开，停不下来） | 火炮、近防、发射器、推进 | 一直吃 |
| switchable（默认开，可手动关） | 雷达、探照灯、ELINT、天线、Energy Regulator | 一直吃，可关 |
| active（默认关，像武器一样按需开） | 干扰器、L50 dazzler | 关着不耗电 |

## 3. (n-1) 规则

`Ship Builds.txt` 基线那句 **`Required power < 110% provided (with exceptions for some ships)`** 里的例外，就是 **(n-1)**：

- 允许「关掉一个可关的部件（通常是一台雷达/干扰器）之后」仍在 110% 以内。
- 所以判定顺序是：先看**全开**是否 ≤ 110%；超了就看**关掉最大的那个可关部件**（n-1）是否 ≤ 110%（或 ≤ 100%，视条件）。
- 如果关掉之后还超，那是真的设计缺陷（`overload`）。如果只是全开超、关一个就够，那是 `ok_shutdown`，可以接受但要写进备注。

## 4. 干扰器怎么耗电

1. 干扰器**默认关闭，关闭时不耗电**。
2. 允许开机的条件是**总供电**够（不是「空闲」够）。
3. 总供电够但**空闲不够**时：它可能只亮一瞬间，然后游戏按耗电优先级关掉别的东西。
4. 船的近防系统可以自动对来袭导弹开机；也可以手动下令。
5. 干扰器按 `Effects` 里写的持续时间内工作，之后自动关、进入装填。
6. **BSHRT / battleshort** 能强制它超过持续时间继续工作，代价是持续的结构伤害。

判定结论分四种：`ready`（全开还能开）、`needs_shutdown`（要先关一个可关部件）、`cannot`（怎么也开不了）、`none`（没装干扰器/没电源）。

## 5. 高耗电船必带 PCC

- `spyglass` 侦察船、`rail` / `md`（mass driver，TE45）这类船自带几台 4250 kW 的轴炮，一定要用 **Plant Control Center** 堆效率，否则供电看着够、其实全被轴炮吃掉。
- Small Reactor Booster 少见：+10% 效率要换 +5% 信号半径和一个模块槽，模块槽在这些 build 里更值钱。
- 判断「这台船的电到底够不够」，先看 `硬消耗 + 常开消耗 ≤ 供电`，再看 `+ 全部干扰器 ≤ 供电`（如果可以开）。

## 6. 已知不确定

- wiki 的 kW 是 0.6.2.6 快照，和当前游戏版本可能有小数点级别的漂移。
- 个别部件的耗电在 wiki 表里缺失（例如部分指挥/绘图类模块），实测会差几十到一两百 kW。
- 效率加成是否对驱动也生效，推算和实测差约 1.6%，暂按「只对反应堆」处理。
