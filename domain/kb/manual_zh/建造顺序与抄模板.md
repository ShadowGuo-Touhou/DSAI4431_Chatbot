# 建造顺序：先抄、后改、最后才从零

Keywords: build, order, copy, template, rename, 配船, 配舰队, 从零, 抄模板, 复制, 改名, 改造, 装配顺序

## 结论

用户要配一艘船、改一艘船、配一支舰队时，按这个顺序选方案：

1. **整艘复制（首选）**——把 good 样本或用户给的那艘船**连同导弹一起**复制，只改船名与呼号。
2. **小改（次选）**——在 good 样本上改 1–2 处（换一个部件、调整弹药），其余保持原样。
3. **从零（最后手段）**——只有用户明确要求从零设计、或所有模板都明显不适用时才用。

## 为什么

- 导弹是整套设计（弹体 / 发动机 / 载荷 / 引导头 / 验证头 / 辅助），单看部件价算不出总价；
  整艘复制能保住原点数和原配平，不会把一艘能用的船改成负供电。
- 抄模板时只需核对 must 七条（CIC / 供电 / 驱动 / 火力 / 损管 / 预算 / 槽位），
  比从零拼装少得多出错空间。
- 游戏里换 1–2 个部件就是玩家的日常改法，这既省事又贴近实战。

## 导弹的特殊规则

- 优先沿用船上已有的导弹（连同 `.missile` 名字）。
- 用户要求换引导头 / 验证头 / 载荷时，**在原有导弹上改那几个槽位**，按部件差价重算点数
  （引导头 1 / 验证头 0.25 / EO 8 / HE 弹头 0.25 这类基准见 `zh/导弹成本构成.md`）。
- 只有用户明确要设计新导弹、或现有导弹完全无法满足时，才从 `missile/*.md` 的模板开始拼。

## 舰队

复制整支舰队再改名 > 在模板舰队上微调 > 从零组队。

## 回答时要说清

- 抄的是哪个模板 / 哪支舰队 / 多少点。
- 这是参考配置，不是唯一解；模组舰队里的部件不代表原版能照抄。
