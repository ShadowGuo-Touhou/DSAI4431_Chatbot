# 交战距离及其推导



来源：玩家整理（中文，非官方，可能早于游戏 0.6.2.6）



NebFC基础：交战距离及其推导

在游戏中我们能够很明确的看到：总的来看，射程越近的武器DPM越高，因此，在距离不同的情况下，不同舰队的克制关系是不同的。比如：两条450CH能在8km以外攻击等离子舰队而不受到伤害，但是如果在7km以内就会很快被等离子-100融化；100炮shuttle能在5km外对没有S3H的鱼雷FFL形成优势，但在4km内会很轻松的被鱼雷FFL击毁。因此，任何一个有理性的玩家都会利用掩体和机动，尽力在交火开始前将自己的舰船移动到自己的优势交战距离。（很多小船玩家并没有意识到这在本质上和大船是一样的逻辑）

由此可得：

1.在正常的对局中，你的对手会尽力将舰船移动到他的优势交战距离，在不知道对方的配置时可以推断出对方的行为动机，因此你需要利用机动避免对方达成这个目的。比如说，一个船以25左右的速度向你开来，还不开火，那大概率是一个Beam舰队。

2.关于配船，由于优势交战距离大部分取决于舰船所携带的武器，将射程差距太大的武器放在同一艘舰船上会导致舰船陷入一个非常尴尬的情况：如果要让两种武器同时开火，那么就不能发挥在这个距离上应有的全部火力，反之则是完全丧失另一种火力，典型的反例就是一半450一半250的LN，以及一半火箭一半100的Shuttle。因此，除了尾部炮塔有时无法使用的舰船（如450BB尾炮带Beam），或者很明确另一种武器只是为了拓展泛用性（如450LN带100副炮）不要携带射程差异太大的武器。

电战对优势交战距离的影响：

优势交战距离不只取决于武器的DPM，还取决于武器效率，如果没有高精度的雷达，那么再高的DPM也是废物，因此，电战对交战距离的影响也是不可忽视的。电战对优势交战距离的影响主要有两种：

1.通过各种方式加长自身的锁定距离，最典型的例子是利用LRT和锁定小船在前方提供锁定，引导后方450、MD、Rail进行炮击，保证己方主要舰队处在安全（或者敌方火力效率低下）的情况对敌方进行炮击。而双方都可以通过相同的方式进行反制

2.通过各种方式缩短对方的锁定距离。最典型的例子就是在没有EO Pike、LRT、Floodlight的情况下，CL在雷达干扰的掩护下和CC、LN在7-8KM对炮，只要保持好距离，也使得保证己方主要舰队处在安全（或者敌方火力效率低下）的情况对敌方进行炮击。

综合运用：以CC-LN-EWR Tug组合为例：

CC-LN-EWR是一个非常经典的组合，舰船配置如下，：

CC：是整个舰队的反导、火控中枢，提供一半的450火力，承担CMD Softkill，并利用长鼻子抗线。

必选配置：

Mk66*3

Aurora*2

VLS-1&Chaff

E70 Commjam

Bulleye

Parallax Radar

可选配置：

Floodlight（强烈推荐携带，反干扰非常好用）

More Aurora （因为BSSJ，不推荐携带过多Aurora，）

Sarissa

LN：整个舰队的反小船、反飞机中枢，一半的450火力。

C65*4

T20*4-6

VLS-1&Chaff

可选配置：

EO Pike

Decoy Container

Bastion PDT

EWR Tug：舰队的眼睛，保证能在长距离上发现目标，EO SoftKill。

EWR ARR

VLS-1&Chaff

L50 Dazzler

可选配置：

J15 Radar Jammer

ES32 Scryer Missile ID System

在这个组合中，CC负责在距离ANS 8-9KM处提供锁定，适当贴着墙壁以避免交叉火力，并用硬杀和软杀保护后面的EWR和LN，而LN则在9.5-11km提供长距离炮击，在确定对手没有导弹时尝试和CC拉开夹角，并用100炮反小船和反飞机，EWR，负责长距离警戒监测敌方动向以进行下一步行动。
