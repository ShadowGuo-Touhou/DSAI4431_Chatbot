# 槽位安装规则：部件太大或类型不对会怎样

Keywords: socket fit, component too large, socket type mismatch, mount size, 槽位, 装不下, 尺寸, 类型不符, 部件太大, 留空, 少了部件

## 一句话结论

不会崩，也不会报错弹窗 —— **那个槽位静默留空**。所以"读档后船上少了几个部件"几乎都是尺寸或类型不匹配。

## 代码依据（`other info/Nebulous.decompiled.cs`）

读档时 `CoroutineLoadShipAsync`（72811–72886）只做两件事：按 `Key` 找槽位（找不到就 `LogWarning("Socket with key … not found")` 并跳过，72828–72833）、按 `ComponentName` 找部件并问 `Hull.CanMountEquipment(component, 舰队阵营)`（72841）。这一步**只看阵营**。

真正的尺寸/类型检查在下一层 `HullSocket.InstallComponent`（约 62250–62280）：

```csharp
if (componentPrefab.Type != Type) {                 // 类型不符
    Debug.LogWarning("Component and Socket type mismatch. …"); return null; }
if (!componentPrefab.TestSocketFit(Size)) {         // 尺寸不符
    Debug.Log("Component too large for this socket"); return null; }
```

返回 null 后没有异常，槽位就空着。

## 尺寸判定：`TestSocketFit`（59973–59985）

看部件的 `RotateToFit`（`enum RotateAxis { None, UpOnly, AnyAxis }`，58604；资产默认 `None`，58883）：

| 模式 | 判定 | 例子 |
| --- | --- | --- |
| `None`（默认） | 三轴各自 ≤ 槽位，不旋转 | C65 6×10×6 进 6×10×6 |
| `UpOnly` | Y 固定，X/Z 可互换 | 8×3×6 的槽位可放 6×3×8 |
| `AnyAxis` | 只比对角线平方和 `x²+y²+z² ≤ X²+Y²+Z²` | FM530 10×8×10 进 8×12×10 |

实存档里 `FM530 'Whiplash' Drive`、`Large DC Locker`、`Reinforced CIC` 都出现过"逐轴不过、对角线过"，说明它们被设成 `AnyAxis`。判断某个部件能不能装时，**先按逐轴算，装不下再按对角线复核**，两者都不行才是真的装不下。

## 类型必须对号

部件类型来自它在 wiki 的分类：`Mounts › …` = 武器/传感器挂载位，`Compartments › …` = 舱室（CIC、损管、弹药库），`Modules › …` = 模块（反应堆、引擎、雷达、机库）。把模块塞进挂载位，游戏只打一条 `Component and Socket type mismatch` 就跳过。

## 自查步骤

1. `python domain/tools/validate_fleet.py <file>` —— 会报 `槽位未知`、`类型不符`、`装不下`、`阵营不符`，并对 AnyAxis 情形给出提示。
2. 只有 `(提示)` 开头的行是"可能合法"，其余都是"游戏里会静默留空"。
3. 拿不准就用游戏的装配界面点一次：装得下的部件在列表里是可点的。
