## 使用注意

1. **FFL 对应三艘船**（Sprinter、Draugr、Ferryman）；被问到 `FFL` 时要说明是哪一艘，不能只给一个答案。`BB` 只有 Solomon 一艘，Worden 是 `CV`。
2. 玩家口语里的 **tug / shuttle / cargo feeder** 分别指 Draugr / Ferryman / Flathead。
3. Mercator 没有缩写，回答时不要造一个。
4. 舰级缩写的依据是**玩家确认**，不是 wiki 字段；wiki 页面里没有这个字段。回答时不要把它说成「wiki 表上写的」，只说「玩家约定的缩写」。
5. Worden 是 **CV**（舰队航母）。它的船体设定源自战列舰，但不要因此把缩写写成 BB —— 早期版本这里写错过一次，已更正。
6. **舰船名一律用英文原名**。官方中文本地化里几乎没有舰名，目前只找到 `Keystone = 拱心石`、`Axford = 艾斯福德`、`Ferryman = 船夫` 三处（后两个还是出现在别的说明文字里）。其余舰船**没有官方中文名**，不要自己音译。用中文提到舰名时按玩家习惯直接写英文（例如「Ocello 级」），必要时补一句「中文译名不保证准确」。中文玩家绝大多数直接用英文名和缩写。

## 旧存档名 → 现在的船（同一个东西）

游戏里有些老舰队还写着旧名字，这些名字和新船是**同一艘船**，只是版本更早时叫法不同：

| 旧名（存档键） | 现在的船 | 缩写 | 依据 |
| --- | --- | --- | --- |
| Shuttle（交通艇 shuttle） | Ferryman Clipper | FFL | 都是小飞剪，槽位 3+3+4 |
| Tugboat（拖船 tug） | Draugr Clipper | FFL | 槽位 5+5+4 |
| Bulk Feeder | Flathead Monitor | MN | 槽位 6+6+7 |
| Bulk Hauler | Marauder Line Ship | LN | 槽位 17+9+8，货船改成线列舰 |
| Ore Carrier | Journeyman Light Carrier | CVL | 槽位 3+8+6 |
| Container Hauler | Moorline Line Ship | CLN | 槽位 11+9+6（存档实测：11 个炮位，wiki 写 10 是旧的） |
| Container Hauler Refit | Container Hauler Refit | CVLN | 与 Moorline 同一套 Container 舰段，槽位 11+9+6 |
| Ocello Cruiser | Ocello Command Cruiser | CC | 同一艘 |
| Mercator Oiler | Mercator Replenishment Oiler | — | 同一艘 |

- 这些旧名 **不作为独立舰级**：查槽位、查船体修正、查舰级都用「现在的船」那一行。
- 船体修正（hull modifiers）里目前只有 **Ocello 带 +10% Powerplant Efficiency**；其余 15 艘没有电力效率修正，所以供电加成只来自 Plant Control Center 与 Small Reactor Booster。
- Container 两行的对应关系是**按槽位数推断**的，如果你知道准确对应请改这张表。
